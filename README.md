

\# Hello Node Server



A beginner-friendly Node.js project demonstrating a basic HTTP server.



\## Features

\- Runs a server using Node.js

\- Responds with "Hello World" at `/hello`

\- Serves a basic HTML webpage at `/`

\- Displays hardcoded student data in a table

\- Handles unknown routes with a 404 response



\## Requirements

\- Node.js LTS

\- npm



\## How to run



1\. Clone or download this repository.

2\. Open a terminal in the project folder.

3\. Run `npm start`.

4\. Open http://localhost:3000 in your browser.



\## Routes



\- `/` — Student data table

\- `/hello` — Hello World response

\- Other routes — Page Not Found



\## Technologies

\- JavaScript

\- Node.js built-in HTTP module

\- HTML

\- CSS
